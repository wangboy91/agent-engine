## 1. 产品定位

企业智能体平台不是聊天页，而是：

- **配置面**：创建、组合、测试、发布、治理智能体及其资源；
- **运行面**：同一智能体安全服务多最终用户，隔离会话/记忆/产物。

产品名对外可用「智能体」；领域模型统一 `Identity`。

两个 Web 入口：

| 入口 | 路由建议 | 用户 | 数据范围 |
| --- | --- | --- | --- |
| 管理控制台 | `/console` | 平台/租户/工作空间管理员、开发者、运营、审计 | 治理与聚合；正文需提权 |
| 用户工作台 | `/app` | 最终用户 | 仅本人授权智能体与运行数据 |

开发调试用 `/ui`（现有 runtime console）继续保留，不替代上述入口。

## 2. 角色与权限

| 角色 | 主要任务 | 默认可见 |
| --- | --- | --- |
| 平台管理员 | 租户、模型网关、全局策略、健康 | 平台治理数据 |
| 租户管理员 | 成员、工作空间、审计、安全策略 | 本租户 |
| 工作空间管理员 | 智能体、Skill、工具、知识、授权 | 指定工作空间 |
| 智能体开发者 | 配置、调试、评测、发布 | 被授权资源 |
| 业务运营 | 质量、审批、任务、产物 | 被授权业务范围 |
| 审计人员 | 只读变更与访问审计 | 审计范围 |
| 最终用户 | 使用已分配智能体 | 仅本人数据 |

## 4. 全局框架

- 左侧固定导航；顶栏：租户 / 工作空间 / 环境、全局搜索、待审批数、当前用户。
- 切换租户或工作空间后立即清空前端缓存并重新请求。
- 每页一个主操作；危险操作与普通操作分离。
- 状态必须同时有文字/图标，不只靠颜色。
- 视觉：Data-Dense Dashboard；主色 `#2563EB`，成功 `#059669`，危险 `#DC2626`；背景 `#F8FAFC`，正文 `#0F172A`，边框 `#E4ECFC`。

## 5. 核心页面详设

### 5.1 总览

指标卡（可点击下钻）：已发布智能体、24h Run、成功率、P95、成本、待审批。  
辅图：失败趋势、模型/Tool 错误分布、高成本智能体。  
快捷入口：创建智能体、导入 Skill、添加工具服务。

### 5.2 智能体列表

列：名称、状态、当前版本、负责人、Skill/Tool 绑定数、授权用户数、最近运行、成功率、更新时间。  
筛选：状态、负责人、标签、环境、模型。  
主操作：创建智能体。  
行操作：查看、复制草稿、停用、查看引用；删除仅限从未发布且无引用的草稿。

### 5.3 智能体详情

```text
智能体名称  Draft v1.4     [保存草稿] [测试] [提交发布]
页签：概览 | 模型 | 提示词 | 对话 | Skill | 工具 | 知识 | 组件 | 渠道 | 版本
左：配置表单    右：目录/校验
底：可折叠调试台（模拟用户、输入、事件、Trace、产物）
```

| 页签 | 内容 |
| --- | --- |
| 概览 | 名称、头像、描述、标签、负责人、使用范围 |
| 模型 | Profile、温度、预算、fallback、超时 |
| 提示词 | System Prompt、模板引用、变量、渲染预览 |
| 对话 | 欢迎语、输入提示、兜底、FAQ、附件、历史策略 |
| Skill | 绑定版本、触发场景、输入映射、优先级 |
| 工具 | 绑定工具、策略、默认参数、审批要求 |
| 知识 | 知识库、召回策略、用户私有记忆策略 |
| 组件 | slot 与组件版本、Mock 预览 |
| 渠道 | Web/API/第三方能力与用户映射 |
| 版本 | Diff、发布说明、评测、回滚、引用 |

发布前统一检查：Schema、引用、权限、Secret、评测、兼容性。

### 5.4 Skill 中心

列表：名称、编码、最新发布版本、状态、引用数、负责人、更新时间。  
详情：核心指令、文件、Schema、允许工具、示例、引用、版本、评测。  
文件只读；编辑通过新草稿或上传新包。

### 5.5 工具与连接器

两层：Tool Service → Operation。  
Service：类型、Base URL、认证引用、工具数、同步状态、健康。  
刷新不得静默覆盖生产版本；生成差异并建草稿。

### 5.6 运行中心

- 会话：匿名用户标识、智能体版本、消息数、状态、最近活动（脱敏摘要）。
- Run：状态、发起主体、资源快照、耗时、用量、错误。
- Run 详情：时间线、步骤树、策略判断、工具调用、产物、安全摘要。
- Artifact：类型、大小、所有者、保留期、下载审计。

### 5.7 治理中心

- 审批队列：风险、等待时长、Tool、智能体、发起人。
- 审批详情：最小必要参数、风险原因、策略来源、影响范围。
- 策略编辑器：作用域、优先级、「以某用户模拟评估」。
- 审计日志不可修改。

### 5.8 用户工作台

**我的智能体**：卡片展示已授权智能体；不展示内部 Prompt/Tool 参数/策略。

**会话页**：

```text
┌────────────┬─────────────────────────┬──────────────────┐
│ 我的会话    │ 消息区（安全步骤摘要）     │ 本次任务 / 产物    │
│ + 新建      ├─────────────────────────┤                  │
│ 历史        │ 附件  输入框      发送    │                  │
└────────────┴─────────────────────────┴──────────────────┘
```

**我的记忆**：用户可查看、纠正、删除长期偏好；共享知识不混入。

## 6. 领域对象（产品语义）

```text
WorkspaceBlueprint@v ── IdentityDefinition ── IdentityVersion
        │                      │
        ▼                      ▼
TenantWorkspace ── TenantIdentity ── IdentityGrant ── EndUser
        │
        └── Session ── Message / Run / Artifact / UserMemory
```

生命周期：`Draft → Review → Published → Archived`（可回滚到历史 Published）。

## 7. 多用户隔离（产品验收）

1. 用户 A/B 使用同一已发布智能体，会话互不可见；
2. B 用 A 的 session/run/artifact ID 请求 → 404/403；
3. A 的记忆不出现在 B 的上下文；
4. 管理员默认只见聚合与脱敏摘要；
5. 管理员读取 A 正文需原因 + 审计，且不能顺带读 B；
6. 切换工作空间后旧缓存/WS 不串数据；
7. 重试/审批恢复保持原始 owner。

## 8. 1.0.1 原型范围

HTML 原型（`prototype/web/`）覆盖：

| 模块 | 页面 | 数据 |
| --- | --- | --- |
| 管理端 | 总览 | Mock 指标 |
| 管理端 | 智能体列表/详情 | 发展规划助手等虚拟示例 |
| 管理端 | Skill / 工具 | 示例资源 |
| 管理端 | Run / 审批 | Mock 时间线 |
| 工作台 | 我的智能体 / 会话 / 产物 | 仅本人视角 |

**r2 增强（权限对齐）：**

| 能力 | 说明 |
| --- | --- |
| 角色切换 | 顶栏可切换平台/企业/空间/开发/运营/审计/员工，验证导航与按钮可见性 |
| 创建智能体向导 | 基本信息 → 模型 → 能力绑定 → 授权 → 发布检查 |
| 导入 Skill | 目录/上传/Registry 表单与校验清单 |
| 产出物目录树 | `users/{owner}/智能体/日期/run/文件`；员工仅本人；管理默认锁定，提权需 reason+审计 |

不在原型中伪造：真实鉴权、OpenAPI 同步、成本账单。

## 9. 完成标准（平台级）

- 平台可发布 Blueprint；租户可安装；
- 管理员可发布绑定 Skill/Tool/Prompt/模型的 Identity 版本并授权两名用户；
- 两用户独立会话且无法互访；
- Run 可追溯精确资源版本；
- 关键页支持 375/768/1024/1440，键盘可操作，明暗主题（原型至少桌面主路径）。

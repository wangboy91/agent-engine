# 常用命令（在 engine/ 下）

首次准备：

```bash
cd engine
uv sync --extra dev
```

之后一律短命令：

| 目的 | 命令 |
| --- | --- |
| CLI | `uv run ae --help` |
| 启动 API | `uv run ae serve --host 127.0.0.1 --port 8050` |
| 跑测试 | `uv run pytest` |
| Lint | `uv run ruff check app tests` |
| 类型检查 | `uv run mypy app` |

仓库根目录也可用包装脚本（Windows）：

```powershell
.\scripts\ae.ps1 serve
.\scripts\ae.cmd skill list
```

前端：

```bash
cd web
npm run dev
```

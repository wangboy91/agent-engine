## 2. 领域对象（建议 Schema）

### 2.1 平台与租户

```text
WorkspaceBlueprint
  id, key, name, description, status, latest_version_id

WorkspaceBlueprintVersion
  id, blueprint_id, version, manifest, status(draft|published|archived),
  created_at, published_at, checksum

IdentityDefinition
  id, key, workspace_blueprint_id, name, description, status

IdentityVersion
  id, definition_id, version, status,

  knowledge_bindings[], component_bindings[],

  id, name, status, features{workspace_customization}, quotas

  id, tenant_id, workspace_key, blueprint_version_id, environment, status

TenantIdentity
  id, tenant_id, tenant_workspace_id, identity_key,

TenantUser
  id, tenant_id, principal_id, display_name, status

IdentityGrant
  id, tenant_id, tenant_workspace_id, identity_version_id|tenant_identity_id,
  grantee_type(user|group), grantee_id, granted_by, created_at
```

### 2.2 运行数据所有权字段（强制）

所有 Session / Run / TraceEvent / Artifact / UserMemory / Approval 至少携带：

```text
tenant_id
tenant_workspace_id
identity_id? / skill_id?
owner_principal_id
session_id? / run_id?
```

唯一约束（ADR）：

```text
TenantWorkspace: (tenant_id, workspace_key)
TenantIdentity:  (tenant_id, tenant_workspace_id, identity_key)
Session:         (tenant_id, tenant_workspace_id, owner_principal_id, session_id)
UserMemory:      (tenant_id, tenant_workspace_id, identity_or_skill, owner_principal_id, memory_key)
```

### 2.3 生命周期

```text
Draft → Review → Published → Archived
                 ↓
              (rollback to older Published)
```

仅 `Published` 可被 Grant 与正式 Run 绑定。

## 3. Principal 与鉴权

```text
Principal
  tenant_id
  principal_id
  principal_type: user | service_account
  workspace_roles[]
  group_ids[]
  auth_session_id
```

规则：

1. 从验证后的 Token 构造，禁止信任 body 里的 `user_id` 作为主体；
2. 管理员代查需 impersonation claim + reason + audit event；
3. 路由级权限只改善体验，真正授权在 use case / repository。

## 5. 仓储查询模板

错误示范（禁止）：

```text
get_session(session_id) → 再在应用层判断 owner
```

正确示范：

```sql
SELECT * FROM agent_sessions
WHERE tenant_id = :tenant
  AND tenant_workspace_id = :workspace
  AND owner_principal_id = :principal
  AND session_id = :session;
```

Memory / Vector metadata filter / Redis key / SSE 订阅同理必须带租户与用户。

## 7. 存储演进

| 阶段 | Catalog | 运行数据 | Secret | Artifact |
| --- | --- | --- | --- | --- |
| 0.1.0 | `.agent/catalog.json` | `.agent/*.json` | 本地明文（仅开发） | 本地目录 |
| **1.0.1 当前** | catalog JSON | **Session/Run/Trace + 平台注册表 → PostgreSQL** | 本地（仅开发） | 元数据 PG + 本地文件 |
| 1.1+ | 版本仓库 | 拆 runtime 独立库（配置已预留） | KMS/Vault | 对象存储 |

### 数据库配置（1.0.1）

```dotenv
# 主库：平台注册表（租户/Identity/Grant/Artifact 元数据/审计）
AGENT_ENGINE_DATABASE_URL=postgresql+psycopg://.../agent_engine

# 运行库：Session / Run / Trace（可选；未设置则复用主库）
# AGENT_ENGINE_RUNTIME_DATABASE_URL=postgresql+psycopg://.../agent_engine_runtime
```

代码入口：`app/infrastructure/config/database.py`（`primary_database_url` / `runtime_database_url`）。  
`SkillEngine.load()` 在任一 URL 可用时自动使用 PG Session/Run/Trace 与 PlatformRegistry，否则回退 JSON。

JSON store 不可作为多副本状态源。
